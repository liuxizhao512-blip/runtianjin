Accounts are not switched on yet

This site is static, so accounts run on a free Supabase project. To enable them:

  1. Create a project at supabase.com.
  2. Open the SQL editor and run supabase/schema.sql from this repo.
  3. Paste your project URL and anon key into SUPABASE_URL and SUPABASE_ANON_KEY at the top of auth.js.

Until then, the training log on the map page still works and saves to this browser only.
