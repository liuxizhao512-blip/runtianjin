About this site

Project overview

Run Tianjin is a lightweight static website built for local runners who want to discover scenic and practical routes in Tianjin with better planning and confidence.

The site uses HTML5, CSS3, and native JavaScript to create semantic pages with a responsive layout for both desktop and mobile screens.

Course purpose

This project was created as a front-end coursework exercise focused on layout design, navigation structure, content presentation, and successful interaction implementation.

Disclaimer

This website is intended for learning and demonstration purposes only. Route information and recommendations are gathered with local context in mind, but users should still consider weather, personal fitness, and real-world conditions before running.
